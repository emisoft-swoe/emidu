    How to Use EMIDU

    • Dashboard: View your complete study analytics, overall average scores, and AI diagnostic insights.
    • Practice Engine: Configure custom multidisciplinary tests with per-subject difficulties, question counts, and specific topic interests, or simulate official national exam mocks (JAMB, WAEC, NECO, GCE, SAT).
    • Weakness AI Drill: Automatically target areas you've struggled with using past test data to strengthen your weak spots.
    • Saved Corrections: Revisit bookmarked question breakdowns and layman explanations.
    • AI Tutor Chat: Ask questions and get instant exam prep help with complete math formatting!

    How to Get Your Free Gemini API Key

    To enable live AI question generation, diagnosis, and tutoring, you need a Gemini API key. It is completely free and takes less than a minute:

    1. Visit the official Google AI Studio website at aistudio.google.com using any web browser.
    2. Sign in using your Google account (Gmail).
    3. Click on the button that says "Get API key".
    4. Click on "Create API key in new project".
    5. Copy the generated alphanumeric key (it starts with AIzaSy...).
    6. Head over to the Settings & Keys page in EMIDU, paste your key into the input field, make sure it is checked as Active, and click Save & Set Active Key!
